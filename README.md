# NTS Billing Portal - Test Automation Project

مشروع أتمتة اختبارات الجودة (QA Automation) لنظام الفواتير **NTS Billing** المبني على **Oracle APEX** باستخدام إطار العمل **Playwright**.

---

## 📌 مميزات وفحوصات المشروع

### 1. شاشة تسجيل الدخول (`apex-login.spec.js`)
* **Invalid Login:** اختبار إدخال بيانات دخول غير صحيحة والتأكد من ظهور رسالة التنبيه المناسبة.
* **Empty Fields:** اختبار محاولة الدخول بحقول فارغة والتأكد من إشعار طلب ملء البيانات.
* **Valid Login:** تسجيل الدخول ببيانات صحيحة واختيار نظام الفواتير والوصول للوحة التحكم الرئيسية (Dashboard).

### 2. شاشة ترميز المحافظات (`geo-coding.spec.js`)
* **التأكد من المسار والـ URL:** فحص عنوان الشاشة والتحقق من أن الرابط يحتوي على `ترميز-المحافظات`.
* **Empty Province:** اختبار ترك اسم المحافظة فارغاً والتأكد من ظهور رسالة الخطأ والتحقق من الحقل المطلوب.
* **Duplicate Province:** اختبار إدخال اسم مكرر وتوثيق سلوك النظام في قبول التكرار (System Bug).
* **Valid Province:** إضافة محافظة جديدة باسم ديناميكي فريد والتأكد من ظهور رسالة النجاح "تم حفظ البيانات بنجاح".

## 🚀 كيفية تشغيل الاختبارات

### المتطلبات المسبقة:
* [Node.js](https://nodejs.org/) (إصدار 18 أو أحدث)

### 1. تثبيت الحزم:
```bash
npm install
```

### 2. تثبيت متصفحات Playwright:
```bash
npx playwright install
```

### 3. تشغيل جميع الاختبارات:
```bash
npx playwright test
```

### 4. تشغيل ملف اختبار محدد:
```bash
# تشغيل اختبارات تسجيل الدخول
npx playwright test apex-login.spec.js

# تشغيل اختبارات ترميز المحافظات
npx playwright test geo-coding.spec.js
```

### 5. عرض تقرير الاختبارات (HTML Report):
```bash
npx playwright show-report
```
