# NTS Billing Portal - Test Automation Project

مشروع أتمتة اختبارات الجودة (QA Automation) المتكامل لنظام الفواتير **NTS Billing** المبني على **Oracle APEX** باستخدام إطار العمل الحديث **Playwright**.

---

## 📌 تغطية الفحوصات والوحدات المنجزة

تمت تغطية شاشة الدخول وكامل شاشات **وحدة ترميز التوزيع الجغرافي** عبر اختبارات مؤتمتة متسلسلة تتعامل بدقة مع عناصر Oracle APEX المعقدة (Popup LOVs, iFrames, Modal Dialogs, Cascading Filters).

### 📑 قائمة ملفات الفحص والشاشات:

| # | الشاشة | ملف الفحص | السيناريوهات المغطاة |
|---|---|---|---|
| 1 | **تسجيل الدخول** | `apex-login.spec.js` | فحص البيانات الخاطئة، الحقول الفارغة، تسجيل الدخول الناجح واختيار التطبيق |
| 2 | **ترميز المحافظات** | `geo-coding.spec.js` | فحص الحقول الفارغة، محاكاة التكرار، إضافة محافظة جديدة بنجاح |
| 3 | **ترميز القضاء-المركز** | `district-coding.spec.js` | فحص إلزامية اختيار المحافظة أولاً، إضافة قضاء للمحافظة المحددة، الحقول الفارغة |
| 4 | **ترميز المناطق** | `area-coding.spec.js` | فحص إلزامية المحافظة والقضاء، إضافة منطقة جديدة بالتسلسل، الحقول الفارغة |
| 5 | **ترميز المحلة** | `mahalla-coding.spec.js` | فحص إلزامية الفلاتر الثلاثة (محافظة، قضاء، منطقة)، إضافة محلة جديدة، الحقول الفارغة |
| 6 | **ترميز الأزقة** | `alley-coding.spec.js` | فحص إلزامية الفلاتر الأربعة، إضافة زقاق جديد، فحص رسائل الخطأ |
| 7 | **ترميز الدار** | `house-coding.spec.js` | فحص الفلاتر الخمسة المتسلسلة، إضافة دار جديدة، التحقق من صحة الحقول الرقمية |
| 8 | **ترميز أنواع الدار** | `house-type-coding.spec.js` | فحص الحقول الإلزامية في النافذة المنبثقة، إضافة نوع دار جديد، فحص زر الإلغاء |

## 🚀 كيفية تشغيل الاختبارات

### المتطلبات المسبقة:
* [Node.js](https://nodejs.org/) (إصدار 18 أو أحدث)
* الاتصال بشبكة النظام (VPN)

### 1. تثبيت الحزم:
```powershell
npm install
```

### 2. تثبيت متصفحات Playwright:
```powershell
npx.cmd playwright install
```

### 3. تشغيل جميع الاختبارات دفعة واحدة:
```powershell
npx.cmd playwright test
```

### 4. تشغيل شاشة محددة مع رؤية المتصفح (Headed):
```powershell
# مثال: تشغيل ترميز الأزقة
npx.cmd playwright test alley-coding.spec.js --headed

# مثال: تشغيل ترميز الدار
npx.cmd playwright test house-coding.spec.js --headed

# مثال: تشغيل ترميز أنواع الدار
npx.cmd playwright test house-type-coding.spec.js --headed
```

### 5. عرض تقرير الاختبارات التفاعلي (HTML Report):
```powershell
npx.cmd playwright show-report
```
